# Performance Testing GPX

Materi Pertemuan 13 mencakup load, stress, spike, endurance, dan volume test. **Tidak ada skrip beban untuk website produksi yang disediakan di sini** demi mencegah gangguan operasional.

Untuk tugas akademik, catat waktu pemuatan halaman secara manual pada browser dan koneksi yang sama sebanyak tiga kali, atau gunakan k6 **hanya pada lingkungan staging yang telah diizinkan** dengan ambang beban sesuai persetujuan. Laporkan p50/p95, error rate, konfigurasi uji, dan keterbatasannya jika sudah dijalankan.
