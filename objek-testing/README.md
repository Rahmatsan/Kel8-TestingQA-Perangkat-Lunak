# Objek Pengujian: GPX

- **Nama aplikasi:** GPX (Gudang Pembangunan Excellence)
- **Alamat:** https://gudangpembangunan.up.railway.app/dashboard
- **Platform:** aplikasi web
- **Jenis pengujian:** End-to-End (E2E)
- **Titik awal:** halaman Login
- **Titik akhir:** Logout/End Session
- **Hak akses:** akun uji yang secara resmi diizinkan pemilik aplikasi

## Cakupan rencana
Autentikasi, dashboard, navigasi, training/assessment, manpower, absensi, aset, consumables, Gojek, dan modul lain yang benar-benar tersedia pada akun uji. Daftar modul **harus diverifikasi saat testing** karena hak akses tiap role dapat berbeda.

## Pembatasan
- Jangan memakai data operasional asli untuk transaksi destruktif.
- Jangan melakukan eksploitasi, stress test, penghapusan massal, atau perubahan produksi tanpa persetujuan eksplisit.
- Gunakan data dummy, lingkungan uji, dan dokumentasi tanpa informasi sensitif.
