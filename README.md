# Testing dan Quality Perangkat Lunak

Repository tugas Semester 7 untuk menyimpan dokumen perencanaan, pelaksanaan, bukti, dan laporan akhir pengujian perangkat lunak.

## Struktur

| Folder | Isi |
|---|---|
| `01-Software-Test-Plan/` | Simpan Software Test Plan (STP), ruang lingkup, strategi dan jadwal pengujian. |
| `02-Test-Scenario/` | Simpan skenario pengujian berdasarkan kebutuhan sistem. |
| `03-Test-Case/` | Simpan test case, langkah pengujian, expected result, actual result, dan status. |
| `04-Test-Data/` | Simpan data uji dummy atau anonim. Jangan unggah data pribadi asli. |
| `05-Bug-Report/` | Simpan daftar bug, severity, langkah reproduksi, dan status perbaikan. |
| `06-Test-Evidence/` | Simpan screenshot atau rekaman bukti pengujian tanpa data sensitif. |
| `07-Final-Report/` | Simpan laporan akhir serta ringkasan hasil pengujian UAS. |

## Alur kerja

1. Tentukan aplikasi yang diuji dan requirement-nya.
2. Buat Software Test Plan dan skenario pengujian.
3. Siapkan data uji anonim, lalu jalankan test case.
4. Dokumentasikan actual result, bug, dan evidence.
5. Susun laporan akhir UAS.

**Catatan:** Jangan upload kredensial, token, atau data pribadi ke repository publik.
