# 06. Checklist User Acceptance Testing (UAT)

UAT memeriksa kecocokan proses GPX dengan kebutuhan operasional pengguna, bukan hanya apakah halaman terbuka. Materi acuan: Pertemuan 9.

| ID | Acceptance Criteria | Langkah uji pengguna | Keputusan |
|---|---|---|---|
| UAT-01 | Pengguna terdaftar bisa login sesuai hak akses | Login dengan akun uji role yang disetujui | NOT RUN |
| UAT-02 | Navigasi menunjukkan menu yang relevan dengan role | Buka Dashboard dan menu yang tersedia | NOT RUN |
| UAT-03 | Filter periode menghasilkan data sesuai pilihan | Pilih periode menggunakan dataset uji | NOT RUN |
| UAT-04 | Validasi mencegah simpan data tidak sesuai | Masukkan data dummy invalid pada sandbox | NOT RUN |
| UAT-05 | Proses logout menutup akses sesi | Logout lalu akses ulang halaman internal | NOT RUN |

Tambahkan nama peran pengguna (tidak perlu data identitas pribadi), tanggal, hasil aktual, catatan perbaikan, dan sign-off resmi secara privat. Persetujuan pemilik untuk **mengizinkan pengujian** berbeda dengan keputusan pengguna untuk **menerima hasil UAT**.
