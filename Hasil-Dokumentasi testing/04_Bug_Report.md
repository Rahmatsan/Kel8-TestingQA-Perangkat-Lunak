# 04. Bug Report GPX

**Status:** Belum ada defect yang dikonfirmasi melalui eksekusi test case dalam pekerjaan ini.

## Aturan pencatatan
Bug dibuat jika hasil aktual tidak sesuai expected result dan dapat ditunjukkan atau direproduksi. Keterangan minimum: ID bug, tanggal, browser/versi, role uji (tanpa kredensial), menu, test case terkait, langkah reproduksi, expected/actual, severity, priority, status, dan evidence yang sudah disamarkan.

**Severity:** Critical (sistem/core data gagal), High (fungsi penting gagal), Medium (fungsi terbatas terganggu), Low (kosmetik/teks). **Priority** boleh berbeda karena mengikuti urgensi perbaikan.

Alur yang digunakan: NEW → TRIAGE → ASSIGNED → FIXED → RETEST → VERIFIED/CLOSED. Jika belum beres, REOPEN. Semua perubahan status perlu tanggal dan sumber verifikasi. Hindari publikasi detail kerentanan keamanan sebelum dilaporkan secara privat ke pemilik.
